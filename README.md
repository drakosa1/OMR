# OMR - Sistema de Consultas SQL con C# y Entity Framework

Proyecto desarrollado para el curso de Diseño de Software.

## Descripción

OMR es una aplicación de escritorio desarrollada en C# utilizando Windows Forms y SQL Server.  
El sistema permite ejecutar consultas básicas, intermedias y avanzadas sobre las bases de datos:

- Northwind
- Pubs

Se utilizó Entity Framework (ORM) y procedimientos almacenados para la manipulación de datos.
